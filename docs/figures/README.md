# Reproducing the figures

Each figure in the main README is generated by one script in this directory. The scripts require the `cfdr` package (installed as described in the main README), NumPy and matplotlib; the published figures were made with NumPy 1.25.2 and matplotlib 3.9.4 on macOS (Apple silicon). Each script writes a light and a dark version of its figure.

## Data

The channel figures compare with the direct numerical simulation of Lee and Moser (J. Fluid Mech. 774, 2015) at Re<sub>τ</sub> = 180. The data are not distributed with this repository. Two files are needed, both available from https://turbulence.oden.utexas.edu:

- `LM_Channel_0180_mean_prof.dat`: the mean velocity profile;
- `LM_Channel_0180_mean_stdev.dat`: the statistical uncertainty of the mean, used as the measurement noise in the calibration.

The backward-facing-step figure needs no external data.

## Commands

The commands are run from the repository root, with the data files in the current directory.

| Figure | Command | Run time |
|---|---|---|
| Calibration coverage and predictive distributions | `python docs/figures/calibration_coverage.py LM_Channel_0180_mean_prof.dat LM_Channel_0180_mean_stdev.dat docs/figures --cache calibration.json --workers 4` | about 50 minutes on four threads (241 solves) |
| Channel profile | `python docs/figures/channel_profile.py LM_Channel_0180_mean_prof.dat docs/figures` | under a minute |
| Backward-facing step | `python docs/figures/step_flow.py docs/figures --cache step_flow.npz` | about a minute |

With `--cache`, the first run stores the solver results and later runs redraw the figures from them without solving again. The calibration results do not depend on the number of worker threads.

## Expected outputs

**Calibration.** The script writes `calibration_coverage_*.png`, `calibration_distributions_*.png` with a PDF and SVG of the light version, and `calibration_support_*.png`, an additional view not shown in the main README. It prints the number of solves (241); the effective sample size (30.0 of 64), the largest normalized weight and the number of distinct resampled draws; the posterior means and standard deviations of a1 and β\*; the number of test points whose standard 90% range contains the reference (1 of 10) and the number whose recalibrated range contains it (10 of 10); the same diagnostics for the independent second sample (effective sample size 27.7, coverage 1 of 10); the Laplace approximation; and the values in the README table. The random streams are seeded and the solves are deterministic, so a rerun on the same platform is expected to reproduce the cached results; on other compilers and processors the last digits can differ.

**Channel profile.** The script writes `channel_profile_*.png` and prints a grid check (the largest change in U<sup>+</sup> between 64 and 128 cells, 0.040) and the values in the README table.

**Backward-facing step.** The script writes `step_flow_*.png` and prints the reattachment length (6.9 step heights).

## Grid convergence

The discretization error quoted for the channel is measured by a regression test that solves the channel on 32, 64 and 128 cells and compares each solution with an independent, grid-converged solution of the same model equations. The test is labelled slow and is excluded from the default test run. It is built and run with:

```sh
cmake --preset dev -DCFDR_BUILD_PYTHON=OFF
cmake --build --preset dev --target test_sst_channel_grid_convergence --parallel 2
ctest --preset dev -R sst_channel_grid_convergence --output-on-failure
```

It takes under a minute and passes when the error decreases at an observed order of at least 1.7 between successive meshes and the root-mean-square error on 128 cells is below 0.025 U<sup>+</sup>; the observed orders are 1.9 and 1.8, and the error on 128 cells is 0.012 U<sup>+</sup>.
